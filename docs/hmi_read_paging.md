# HMI 读取：完整性、分页与去重

## 读取方式

- 控件目录：`tc_hmi_read(file="Desktop.view", include_content=false, max_controls=40)`。
  返回 ID/类型目录，按 `next_control_offset` 继续；完整属性与绑定用精确 `control_id`。
- 源码：显式 `include_content=true`，返回连续片段。按 `next_content_offset` 继续。
  游标单位为 .NET UTF-16 code units；中文、emoji 场景直接沿用返回值，不自行用字符串长度估算。
- 清单和源码是不同模式，可以先清点再读取源码。`control_offset` 不影响精确 ID 查询。
- CLI 对应 `hmi read --control-offset N --content-offset N`；外部 MCP 使用相同字段。

## 不再二次静默截断

Agent 的模型上下文不再固定只留下前 24 个控件或前 1200 字符源码。
控件目录按序保留到上下文预算，源码保持连续、不拼接首尾；返回计数、截断标记、下一页位置
对应模型实际收到的内容。工具原始结果仍保留用于 UI/执行记录。
目录省略样式等详细属性是明确的目录视图，不等于控件完整属性；详情仍用 control_id。
绑定返回的是本页选中控件的子集，需要全部绑定审查时使用 tc_hmi_bindings。

## 去重

- 身份包含工程、文件、精确控件 ID、是否请求源码、两个分页位置。
- 仅重复同范围，或结果证实已经覆盖新请求时拦截。
- 已截断的清单允许扩大上限；模式切换及下一页始终是新范围。
- 判断依据是模型实际收到的结果，不是 UI 的原始大结果。
- 同一个不完整请求原样重试仍会被拦截，返回的续读位置用于继续，而不是循环重读第一页。
- 记录包含已保存文件的大小、修改时间；保存变化或 Agent 写入导致缓存版本变化后失效。
  读期间发生变化、路径缺失或无法验证指纹时不去重。

## 真实性边界

当前 HMI 文件读取仍是已保存文件，`source=saved_file`、`live_xae=false`、`dirty_unknown=true`。
本次没有将其冒充 XAE 未保存编辑缓冲，也没有自动保存工程。
读文件前后核对大小/时间，不能替代强事务快照或检测同尺寸同时间戳的外部改写。

## 验证

`tests/test_hmi_read_paging.py` 覆盖本次 60→80、清单→源码、完整结果去重、保存后失效、
模型上下文续读、Unicode 游标、真实 PowerShell 78 个控件分两页无遗漏等回归。
本地工程只读实测：78 控件按模型预算返回 57 + 21；无 PLC/HMI 写入、构建、启动或激活。
