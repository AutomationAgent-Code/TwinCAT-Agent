# FB 内部方法预审

未限定调用 `CalcPidiOutput()` 的解析顺序为：局部/父 FB 变量实例、当前 FB 方法、全局函数/FB 声明。
当前 FB 来自候选 `FUNCTION_BLOCK` 声明，方法正文来自 `enclosing_declaration`；父对象用精确 TIPC 路径绑定，成员签名按需只读并缓存。

`THIS^.Method()` 仅在已确认 FB 作用域内作为当前实例调用处理；不放宽一般指针、继承、接口和抽象派发的未验证限制。
内部 PRIVATE 方法允许调用；外部受限方法仍不能仅凭签名放行。签名名称、参数方向、类型、返回值沿用语义检查。

候选批次读取成员时不得用 FB 本体声明替代方法签名。找不到真实成员、签名不完整或无法确认的语义仍阻止写入。
离线预审通过不代表真实 TwinCAT 编译、下载或运行行为已通过；不启动额外 XAE 实例。
