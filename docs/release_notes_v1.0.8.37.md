# TwinCAT Agent v1.0.8.37 更新日志

发布日期：2026-08-14

## 多对话与后台任务

- 每个 TwinCAT 解决方案使用独立的 `.TwinCATAgent/agent.db`，保存多对话、父子任务、消息、压缩摘要和中断恢复点。
- 支持创建、切换、重命名、分叉、归档和转交对话，并支持项目内对话互发结构化消息。
- 增加后台 `worker/review/research` 子任务，并发上限为 2；关闭或重载 WebView 不会取消任务。
- 支持父对话等待、汇总、停止和显式恢复子任务；服务重启后未完成任务转为“可恢复”，不会自动消耗 token。
- Worker 只能执行只读 XAE 操作；低风险写入生成待审批提案，高风险运行时操作不会由 Worker 直接执行。

## 上下文、记忆与预算

- 每个对话保留独立近期上下文、语义摘要和网络中断恢复快照，继续工作时不再丢失原任务。
- 增加项目共享结构化记忆，支持事实、决策、偏好和约束；冲突不静默覆盖，敏感凭据拒绝保存。
- 记录每次 Worker 的模型、调用次数、输入/输出 token、状态、耗时和错误。
- 取消固定 turns 上限。Worker 可选显式 `token_budget`，默认 `0` 表示不设硬上限。

## 并发与可靠性

- XAE/COM 调用改为按目标 XAE PID 串行：同一实例避免 COM 重入，不同 XAE 实例可并行。
- 修复后台任务槽跨事件循环复用的问题；服务异常重启不会沿用旧循环对象或僵尸任务引用。
- 项目级事件总线按数据库绝对路径隔离，实时同步 Worker 状态、结果和改动提案，并清理断线订阅。
- 后端正常关闭时会取消并收口后台任务，状态和用量持久化。

## 数据维护

- 增加项目数据库完整性检查、SQLite 一致性快照和可审计 JSON 导出。
- UI“对话”菜单新增“数据维护”；快照位于 `.TwinCATAgent/backups/`，导出位于 `.TwinCATAgent/exports/`。
- 新增 `project_data_health`、`project_data_backup`、`project_data_export`，当前工具总数为 89。

## 验证

- Python 编译检查通过。
- 完整自动化回归：`227 passed, 22 subtests passed`。
- 安装器构建继续执行敏感文件检查，禁止打入 API Key、授权私钥、客户授权文件和聊天历史。
