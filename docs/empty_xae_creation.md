# 空白 XAE 创建工程

XAE 已连接但没有解决方案属于正常状态。Agent 首轮提供连接检查、模板目录、新建与打开工程工具。

空白状态的对话存放在后端 `.empty_xae/<随机作用域>/agent.db`，按 XAE PID 与进程创建标识隔离，不读取旧全局 `agent.db`，也不导入全局 JSON 历史。同一后端运行期间，同一空白窗口重连保留草稿；打开工程后结束该临时作用域，再关闭工程或重新启动 XAE 将获得新的空白对话。原数据库文件保留，不自动删除。后端重启后不会自动恢复旧临时作用域。

1. `tc_solution_templates` 返回实际可用模板。安装包附带 `basic` 空白系统工程模板，开发目录可提供更多模板。
2. `tc_create_solution(name, output_dir, template)` 在指定绝对父目录下建立新的 name 目录，从模板生成新 GUID，再通过原 XAE PID 打开并回读解决方案。
3. 已有目标目录、XAE 已打开工程或创建期间出现其他工程时拒绝覆盖；生成文件保留以便恢复。失败时先读取当前状态，不盲目重复创建。
4. `basic` 创建解决方案及 TwinCAT 系统项目；随后使用 `plc_create_project` 添加 PLC，再进行编程。创建本身不登录、启动或激活运行时。
5. 新路径经回读确认后更新当前轮的宿主绑定和工具目录。当前轮继续保存在原对话数据库，结束后的工程绑定将消息、摘要、恢复信息和图片附件复制到新工程的一条新对话，原记录保留。

空白 XAE 也可通过 `tc_open` 打开已有解决方案并接续。外部手动切换工程仍受原会话保护限制。

本轮验证使用真实 basic 模板生成与模拟 DTE 边界测试，没有在用户当前 XAE 中创建测试工程。安装包资源已纳入构建脚本；源码变更并不表示运行中的后端已加载。
