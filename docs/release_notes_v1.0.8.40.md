# TwinCAT Agent v1.0.8.40

## 新增

- 右侧项目对话栏支持置顶和取消置顶。
- 置顶状态保存在当前项目的 `.TwinCATAgent/agent.db`，重启 XAE 后仍然有效。
- 置顶对话始终排在普通对话之前，普通对话继续按最近更新时间排序。
- 每个对话可设置独立的工程相对工作目录，例如 `.`、`PLC1/POUs` 或 `Motion`。
- 工作目录会进入当前对话的模型上下文；分叉对话会继承来源对话的目录。

## 兼容性

- 已有项目数据库会自动增加 `pinned` 字段，不会清空或改写历史对话。
- 工作目录只允许工程内相对路径，拒绝绝对路径及包含 `..` 的越界路径。
