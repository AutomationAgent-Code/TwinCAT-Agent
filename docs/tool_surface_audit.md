# 工具目录与结果精简审查

当前注册工具 208 个，默认模型目录收起 3 个旧入口；底层执行及显式分配兼容保留，不自动转发写操作。

## 保留边界

实时/磁盘/活动编辑器读取、单变量动态读取/批量标量读取、Build/诊断/静态分析、移除/删除、预览/执行具有不同契约，不因名称相似删除。未使用次数不是删除依据。

## 输出策略

大结果保留结构化预览；通用压缩另保留 decision_evidence（错误等级、门禁、写入状态、语义、数量及代表性位置），不把字段省略当作通过。PLC 预检使用专用摘要。原始结果仍留在执行台账和按需展开界面，未删除日志或用户历史。专用读取分页和审批令牌返回不改动。该改动不是所有工具逐一现场验收。
