# PLC 工具路径契约

- `tree_path`：精确 `TIPC^…` 身份；COM 读取和对象写入使用。
- `source_path`：目录返回的 `项目^…文件.TcPOU` 等已保存索引身份；不是物理文件路径。
- 旧 `path` 保留严格兼容，不再推荐模型生成；多个字段只能表达同一个身份，否则访问 XAE 前拒绝。

`plc_read_smart` 和 `plc_read_fast` 按身份选择来源，无需猜测 `live`。显式 live 与身份冲突时拒绝。
`plc_read` 始终实时读取；索引路径使用 smart/fast。批量混合两种身份需拆成两个批次，不暗中跨来源切换。
显式索引读取失败不回退到同名 COM 对象。写入只接受 COM 身份，不从索引路径按名称推导目标。

UI 保留旧结果兼容；交给模型的读取/查找/目录结果将可判定的 `path` 转为类型明确的字段。
保存和成员修改的哈希基线是不可改写的令牌，内部 path 原样保留。
创建/候选审核的树路径同样可以使用 tree_path；创建的父目录与候选对象完整路径仍服从各工具契约。
