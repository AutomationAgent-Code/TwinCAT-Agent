# TwinCAT Agent v1.0.8.38 更新日志

发布日期：2026-08-14

- 修复对话下拉框收到失效 `thread_id` 时进入 `selectedIndex = -1`、只显示空箭头的问题。
- 当前选择不在列表中时自动回落到首个有效对话；没有活动对话时显示“暂无对话”，不再显示空白控件。
- 数据库只剩归档记录时自动创建新的“主对话”，保证后端始终有一个可绑定的活动会话。
- 对话下拉框增加最小宽度，避免短标题或空状态时收缩成箭头。
- 补齐“数据维护”按钮的显式 DOM 引用，避免依赖 WebView 的隐式元素全局变量行为。
- 删除后台子任务功能及其 UI 入口；保留普通多对话、分叉、项目记忆和对话间消息。
- 从模型工具中移除 `thread_create`、`thread_wait`、`thread_collect`、`thread_handoff`，工具基线调整为 85。
- 本地更新器会识别占用 8765/8766 且命令行为 `tc_agent.backend` 的旧开发后端，避免端口占用导致新版本页面未生效。
