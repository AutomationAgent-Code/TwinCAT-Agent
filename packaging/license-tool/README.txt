 TwinCAT Agent 授权码签发工具（供应商专用）
========================================================================

运行 TwinCAT-Agent-License-Issuer.exe，不需要安装 Python。

使用步骤：

1. 点击“选择…”载入产品 RSA 私钥 private_key.pem。
2. 粘贴客户授权页显示的 TwinCAT System ID（GUID）。
3. 填客户/公司名称。
4. 选择有效天数，或勾选“永久授权”。
5. 点击“生成授权码”。
6. 复制生成的 TCAG1. 开头授权码发给客户。

授权记录：

· 每次生成成功后会自动保存授权记录。
· 点击主界面右上角“查询授权记录”，可按客户名、TwinCAT System ID 或授权编号查询。
· 双击记录或点击“载入到发码界面”，可以重新查看、复制或保存原授权码。
· 记录库保存在：
  %LOCALAPPDATA%\TwinCAT Agent License Tool\license_records.db
· 覆盖升级授权工具不会删除记录库，请定期备份该文件。

安全要求：

· 本工具包【不包含私钥】，第一次使用必须手动选择。
· private_key.pem 只能保存在供应商受控电脑或加密离线介质中。
· 绝对不要把私钥、这个供应商工具或整个授权工具目录发给客户。
· 可以发给客户的只有 TCAG1. 开头的授权码。
· 工具仅记住私钥文件路径，不复制私钥内容。
· 授权记录库包含已签发的授权码，应按内部业务资料保护，不能发给客户。

申请处理：

· 点击“导入申请表…”可导入官网导出的 twincat-agent-submissions.csv，或单条 JSON 申请。
· CSV 中的反馈会自动跳过；包含多条申请时可在列表中选择目标申请。
· 导入时会按 TwinCAT System ID 检查历史授权，并显示最近一次授权状态；重复签发前会确认。
· 签发完成后点击“生成回复邮件”，会打开默认邮件客户端的回复草稿。
· 也可以填写 Gmail 应用专用密码后点击“发送回复邮件”，默认发件邮箱为 zxctian@gmail.com。
· 发送前会弹出确认；应用专用密码只在本次运行内存中使用，发送后清空，不写入配置文件。
· 回复邮件正文包含基础使用教程和 AI/PLC 工程免责声明。
· 回复邮件会自动包含百度网盘安装包链接、提取码 8888，以及 GitHub 备用下载链接。

当前产品私钥默认保存在开发机：
G:\claude\TwinCAT-Agent-License-Secrets\private_key.pem
