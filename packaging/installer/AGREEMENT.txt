一、使用范围
1. TwinCAT Agent 的使用同时受本项目 LICENSE、TwinCAT/Beckhoff 许可条款、所配置的模型或 API 服务商条款，以及适用法律约束。
2. 你应确保自己拥有安装、运行 TwinCAT XAE、访问项目文件和使用相关 API 的必要权限，并自行管理 API Key、账号、配额和费用。

二、安装与操作责任
1. 安装器会把程序放入本机用户目录，并按页面选项创建快捷方式。只有勾选 XAE 嵌入时，安装器才会请求管理员权限修改 TwinCAT XAE 扩展。
2. 在让 Agent 生成、修改、编译或部署 PLC/HMI 配置前，请先备份项目，并由具备相应资质的人员审核结果。你对现场设备、控制逻辑、安全功能和由此产生的后果负责。
3. 请勿用本软件绕过 TwinCAT、设备、网络、信息安全或组织内部的授权、审查和变更流程。

三、数据与隐私
1. 安装器本身不会因为安装步骤自动上传 PLC 项目或聊天内容。升级时会在本机保留已存在的配置、授权信息和历史记录，以便继续使用。
2. Agent 运行时，提示词、项目上下文或其他数据是否发送给模型/API 服务商，取决于你的 Provider 配置和具体操作。请在使用前审阅服务商的隐私政策、数据处理方式和跨境传输规则。
3. 你应避免把不应离开本机或组织边界的密钥、个人信息、生产机密和受保护数据提交给未获批准的服务商。
