========================================================================
 TwinCAT Agent 一键安装程序
========================================================================

安装：

1. 完全关闭 TwinCAT XAE。
2. 双击 TwinCAT-Agent-Setup-vX.Y.Z.exe。
3. 安装器会自动识别 TwinCAT Build 4024/4026。
4. 需要 XAE 内面板时，勾选“嵌入 TwinCAT XAE”。
5. 点击“立即安装”。只有勾选嵌入时才会弹出一次 UAC。
6. 嵌入模式会打开 XAE；仅后端模式会打开本地浏览器界面。

安装内容：

· TwinCAT Agent 后端、便携 Python、倍福文档索引
· TwinCAT XAE 扩展（可选，兼容 Build 4024/4026）
· 开机启动项（后端始终以普通用户权限运行）
· 桌面和开始菜单快捷方式
· 图形卸载程序

默认安装位置：

%LOCALAPPDATA%\Programs\TwinCAT Agent

升级：

直接运行更高版本的 TwinCAT-Agent-Setup-vX.Y.Z.exe。Provider/API Key、本机授权和项目历史会保留。

卸载：

从开始菜单选择“TwinCAT Agent → 卸载 TwinCAT Agent”。
本机授权文件和项目目录中的历史对话默认保留。

说明：

当前测试版尚未购买代码签名证书，因此 Windows SmartScreen 可能显示“未知发布者”。
请核对安装文件来源和 SHA256 后运行。正式销售版本应使用 EV/OV 代码签名证书签名。
