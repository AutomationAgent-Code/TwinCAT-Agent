========================================================================
 TwinCAT Agent —— 便携测试包（免安装 Python）
========================================================================

推荐直接使用 `TwinCAT-Agent-Setup-vX.Y.Z.exe` 一键安装。下面的手动步骤仅用于便携包诊断、
无安装器的离线环境，或一键安装失败后的排查。

这是一个自包含的测试包，用于在【另一台已装 TwinCAT / TcXaeShell 的电脑】上
试用 TwinCAT Agent 面板。里面自带了一份可直接运行的 Python，目标机不需要
另外装 Python、pywin32 或任何依赖。

------------------------------------------------------------------------
 目标机前提
------------------------------------------------------------------------
· 已安装 TcXaeShell（TwinCAT XAE Shell，即写 PLC 用的那个 IDE）。
  —— 面板是嵌在 TcXaeShell 里的扩展，没有它装不了。
· Windows 10/11 64 位；客户机不需要启用 PowerShell。
· 安装扩展那一步需要管理员（要写 Program Files）；跑后端【不要】用管理员。

------------------------------------------------------------------------
 安装
------------------------------------------------------------------------
推荐双击 TwinCAT-Agent-Setup-vX.Y.Z.exe，通过图形安装器选择是否嵌入 XAE。
安装器自身处理 UAC、扩展复制、快捷方式和卸载，不调用 powershell.exe。

便携目录仅用于诊断或仅后端运行：双击 Start-Backend.vbs（普通双击，【不要】管理员）。
   它在后台悄悄跑一个本地服务（端口 8765/8766），没有窗口是正常的。
   自检：浏览器打开 http://127.0.0.1:8766 能看到面板界面，就说明后端起来了。

然后完全关闭再重新打开 TcXaeShell，从菜单打开『TwinCAT Agent』面板即可。

------------------------------------------------------------------------
 首次使用：设备授权
------------------------------------------------------------------------
首次打开只显示授权页。点击“复制”取得本机 TwinCAT System ID，把 System ID 发送给
软件供应商。收到 TCAG1. 开头的授权码后，粘贴并点击“验证并进入”。

授权码仅与当前 TwinCAT System ID 绑定，复制到另一台电脑不能使用；System ID
改变后需要重新授权。授权成功后记录保存在
%LOCALAPPDATA%\TwinCAT Agent\license.json，覆盖升级本软件不会丢失。

------------------------------------------------------------------------
 授权后：填自己的模型 Key
------------------------------------------------------------------------
本包不含任何 API Key。打开面板后点右上角 ⚙ 设置 → 添加一个 Provider：
· 选模板（如 DeepSeek），填入你自己的 API Key，模型填 deepseek-chat，保存启用。
· 国内可直连的模型（DeepSeek 等）默认【直连】，不用开代理。
· 只有访问需要翻墙的端点（如 Anthropic 官方）时，才在那个 Provider 的
  “代理 Proxy（可选）”里填 http://127.0.0.1:7890 之类。

------------------------------------------------------------------------
 开机自启（可选）
------------------------------------------------------------------------
想每次开机自动起后端：按 Win+R 输入 shell:startup 打开启动文件夹，
把 Start-Backend.vbs 的【快捷方式】拖进去即可（仍是非管理员运行）。

------------------------------------------------------------------------
 卸载
------------------------------------------------------------------------
从开始菜单选择“TwinCAT Agent → 卸载 TwinCAT Agent”。卸载器会自行请求 UAC，
不调用 PowerShell。之后重启 TcXaeShell 生效。

------------------------------------------------------------------------
 排障
------------------------------------------------------------------------
· 面板空白/连不上：确认 Start-Backend.vbs 已双击启动，且浏览器能打开
  http://127.0.0.1:8766。看日志 _backend.log（包根目录下）。
· 面板显示“未打开解决方案”/工具报 XAE not running：后端一定要【非管理员】
  启动，和 TcXaeShell 同权限，否则 COM 看不到 IDE。
· 面板里没出现『TwinCAT Agent』菜单：确认扩展已复制到
  <TcXaeShell>\Common7\IDE\Extensions\TwinCAT Agent\，并【完全重启】TcXaeShell。
· 报 WinError 10061：一般是残留系统代理；本版默认直连，除非你在 Provider 里
  显式配了代理。把那台机器的系统代理关掉或在 Provider 里清空代理即可。
· 授权码提示设备不匹配：确认发给供应商的是当前授权页显示的 TwinCAT System ID；
  System ID 改变后需要重新签发。
